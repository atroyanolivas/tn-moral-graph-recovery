# Tensor Network Moral Graph Recovery

Official code for **"Tensor Network Moral Graph Recovery of Discrete Probability
Distributions"** — Álvaro Troyano Olivas, Chi-Hang Fred Fung, Hans H. Brunner,
Momtchil Peev, Vicente Martín.

📄 **Paper:** [arXiv:2609.09258]([https://arxiv.org/abs/XXXX.XXXXX](https://arxiv.org/abs/2609.09258)

## What this does

Recovers the **moral graph** of a causal DAG — the undirected graph connecting
direct causes and the co-parents of v-structures — from a probability
distribution $p(V_1,\dots,V_m)$ over discrete variables, without interventions.

The method fits a **fully connected tensor network (FCTN)** to $p$, with every
bond matrix parameterized as

$$B_{ij} = J_{ij} + C_{ij}, \qquad C_{ij} = U_{ij}V_{ij}^{\top},$$

where $J_{ij}$ is a fixed all-ones matrix (the *disconnected baseline*: with
$C_{ij}=0$ the two sites contract independently) and $C_{ij}$ is a trainable
low-rank correction. Training minimizes

$$
J(\theta) = \lVert p - TN(\theta)\rVert_2^2 + \frac{\beta}{2}\sum_{\{i,j\}}\bigl(\lVert U_{ij}\rVert_F^2 + \lVert V_{ij}\rVert_F^2\bigr),
$$

where the Frobenius penalty on the factors is the variational form of the
nuclear norm $\lVert C_{ij}\rVert_*$ (no SVD is ever computed during training).
The penalty drives corrections on bonds that $p$ does not need to zero, and the
**effective graph** — bonds whose correction has effective rank ≥ 1 at tolerance
`1e-6` — is read directly from the optimized solution.

The paper proves that, under faithfulness and positivity of $p$ and a
no-implicit-rerouting condition on the local tensors, *every* optimal
zero-error FCTN has effective graph exactly equal to the moral graph, and gives
approximate-recovery bounds (via Fannes–Audenaert continuity of conditional
mutual information) together with a sufficient condition on $\beta$.

## Repository layout

```
tn_causal/                     core package
├── bond_matrix.py             J + U Vᵀ bond parameterization, variational penalty
├── fctn.py                    FCTN ansatz and contraction
├── optimizer.py               Adam optimization of the objective
└── recovery.py                effective-graph extraction (rank-based pruning), metrics

experiments/
└──  synthetic_experiments.py   Table 1

tests/                         unit tests: bonds, contraction, optimizer, pruning
```

## Installation

```bash
git clone https://github.com/atroyanolivas/tn-causal-moral-graph.git
cd tn-causal-moral-graph
pip install -e .
```

Python ≥ 3.X; dependencies (PyTorch, NumPy, Matplotlib) are declared in
`pyproject.toml`.

## Reproducing the experiments

### Table 1 — synthetic ground-truth recovery

```bash
python moral_graph_experiments/synthetic_experiments.py
```

Common settings for all models: Adam, learning rate `1e-2`, `3000` iterations,
pruning tolerance `1e-6` on the singular values of $C_{ij}$.

| Model                          | m | d | r_max | β       | ε*            | Precision | Recall |
|--------------------------------|---|---|-------|---------|---------------|-----------|--------|
| Chain ($X{\to}Z{\to}Y$)        | 3 | 4 | 2     | 1e-3    | 3.42e-2       | 1.000     | 1.000  |
| Fork ($Z{\to}X,\ Z{\to}Y$)     | 3 | 3 | 3     | 1e-3    | 3.12e-6       | 1.000     | 1.000  |
| Collider ($X{\to}Z{\leftarrow}Y$) | 3 | 5 | 3  | 1e-4    | 9.36e-5       | 1.000     | 1.000  |
| Diamond ($X{\to}Z{\leftarrow}Y$, $Z{\to}W$) | 4 | 4 | 3 | 1.7e-2 | 1.16e-2 | 1.000 | 1.000 |

The moral graph is recovered exactly in all four cases. Raw outputs of the runs
are committed as `moral_graph_experiments/figen_*.csv` and are regenerated by
the script.

### Tests

The suite covers the four core modules:

| File | What it checks |
|---|---|
| `tests/test_bond_matrix.py` | `J + UV^T` bond parameterization and the variational penalty |
| `tests/test_fctn.py` | FCTN ansatz and contraction correctness |
| `tests/test_optimizer.py` | objective, gradients, and Adam training loop |
| `tests/test_thresholding.py` | rank-based effective-graph extraction (pruning at `tol=1e-6`) |

Install the test dependencies and run from the repository root:

```bash
pip install -e .
pip install pytest
python -m pytest
```

Useful variants:

```bash
python -m pytest -v                          # one line per test
python -m pytest tests/test_bond_matrix.py   # a single file
python -m pytest -k thresholding             # tests whose name matches
```

## Reproducibility notes

- The rank tolerance `1e-6` exploits the empirical gap between optimizer noise
  (singular values ~1e-8) and genuine corrections (~1e-3 and above); see the
  paper, Section 3.5.
- Random seeds are fixed in the experiment scripts. Exact values of
  $\varepsilon^*$ can vary slightly across hardware and library versions; the
  recovered graphs are stable across runs.
